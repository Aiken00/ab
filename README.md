# Banking System REST API

Тестовый проект банковской системы, разработанный на Spring Boot.

## Реализованный функционал

### Пользователи

* Создание пользователя
* Получение пользователя по ID
* Поиск пользователя по email
* Получение списка пользователей с пагинацией

### Счета

* Создание счета пользователю
* Получение счета по ID
* Получение списка счетов
* Получение текущего баланса счета
* Пополнение счета
* Списание средств со счета

### Переводы

* Перевод денежных средств между счетами
* История операций по счету
* Фильтрация операций по диапазону дат

## Бизнес-правила

* Email пользователя должен быть уникальным
* Один пользователь может иметь не более 3 счетов
* Баланс счета не может быть отрицательным
* Нельзя выполнять перевод на тот же счет
* Валюта счета задается при создании и не изменяется
* Сумма операции должна быть больше нуля
* Перевод выполняется в рамках транзакции (@Transactional)

## Запуск проекта

### 1. Создать базу данных PostgreSQL

Например:

```sql
CREATE DATABASE bank_db;
```

### 2. Настроить application.yml

Указать параметры подключения к БД:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/bank_db
    username: postgres
    password: your_password
```

### 3. Запустить приложение

```bash
mvn spring-boot:run
```

или через IntelliJ IDEA:

```text
Run -> FirstProjectApplication
```

## Тестирование

Реализованы unit-тесты для сервисного слоя с использованием Mockito:

* Успешный перевод между счетами
* Проверка ошибки при недостаточном балансе

Также реализован интеграционный тест API.
